## Phase Goal

**As a** автор роликов, запускающий очередь задач на своём ПК, **I want to** чтобы задача с записью шла через новый `pipeline::record` поверх трейта `Host` и при любом сбое старта игры останавливалась в срок с типизированной ошибкой в карточке и в `record.log`, **so that** очередь не висит бесконечно, а я сразу вижу, что именно пошло не так.

<objective>
Перевести маркеры консоли на формат с nonce задачи (D-11) и выводить ожидаемый набор дублей из плана до начала записи (TAK-01, D-12): `renderer` пишет `CS2C <nonce> SCRIPT / TAKE_START n / TAKE_END n / ALL_DONE`, отдаёт `TakePlan` на каждый дубль; `pipeline::plan_player` генерирует nonce и кладёт `takes` и `nonce` в `Plan`; приложение на старом пути записи продолжает читать метки дублей и не теряет «дубли уже записаны».

Purpose: маркеры — общий контракт генератора cfg и парсера машины записи (01-04); без SCRIPT и TAKE_START машина не может отличить «скрипт не запустился» от «дубль не начался» (LCH-03), а без набора дублей из плана нечем посчитать M и дедлайн дубля.
Output: обновлённый `renderer`, `Plan { takes, nonce }`, нормализованный `plan_hash`.
</objective>
