## Phase Goal

**As a** автор роликов, который ставит задачи на запись в очередь и уходит от компьютера, **I want to** чтобы запись не начиналась в неисправном окружении, отменялась за секунды в любом состоянии и закрывала только те `cs2.exe` и `HLAE.exe`, которые запустило само приложение, **so that** ночная очередь не висит, моя собственная игра не убивается, а причина остановки видна сразу.

<objective>
Подготовить базу к фазе 2 одной миграцией (версия 3): JSON отчёта предпроверки на задаче и пара «сборка CS2 / версия HLAE» последней удачной записи (D-04); добавить статус «отменяется» (D-11) и запросы для уборки после падения приложения (D-08). Карточка задачи получает минимальные ветки нового статуса, чтобы приложение собиралось и статус был виден сразу.

Purpose: предпроверка (02-05/02-06) пишет отчёт в задачу и читает пару последней удачной записи; отмена (02-07) ставит «отменяется» синхронно по нажатию; старт приложения (02-06) находит прерванные задачи.
Output: обновлённый `crates/store/src/lib.rs`, ветки статуса в `crates/app/src/jobs_page.rs`.
</objective>
