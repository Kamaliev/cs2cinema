## Phase Goal

**As a** автор роликов, который ставит задачи на запись в очередь и уходит от компьютера, **I want to** чтобы ролик собирался только из проверенных дублей, упавшую задачу можно было повторить кнопкой без повторного скачивания и планирования, а задача, прерванная падением приложения, честно помечалась «прервана», **so that** битый дубль не попадает в ролик, повтор не стоит лишнего часа, а журнал и карточка сохраняют улики всех попыток.

<objective>
Дать крейту `host` два умения фазы: назвать свои процессы полной идентичностью и завершить осиротевший процесс прошлого экземпляра приложения только при полном совпадении (D-15, RET-04), а фейку — отвечать как настоящий `ffprobe` по дублям и разыгрывать сценарии «обрезанный дубль», «нет звука», «другое разрешение», «файл ещё дописывается» (D-17, TST-02).

Purpose: Job Object с `KILL_ON_JOB_CLOSE` закрывает игру вместе с упавшим приложением, но игра, принятая без job (`adopted_without_job`), и редкие остатки требуют страховки по (PID, время создания) — это запасной путь TMO-05. Сценарии ffprobe нужны машине записи (03-04) и тестам TST-02 (03-05) без CS2.
Output: изменённые `host/src/lib.rs`, `win/process.rs`, `win/mod.rs`, `fake.rs`, тесты `win_session.rs` и страж `own_processes.rs`.

**Допущения:**
- Список образов для завершения — только `cs2.exe` и `HLAE.exe` (D-15 называет их); дочерний ffmpeg HLAE завершается вместе с job и в идентичности не попадает.
- Страж фазы 2 «у трейта хоста нет метода завершения по PID» уточняется, а не снимается: единственный разрешённый метод принимает `&ProcIdentity` (PID + время создания + образ), что и есть запасной вариант TMO-05 и решение D-15.
- Ответчик ffprobe фейка включён по умолчанию: он срабатывает только на аргументы с `-show_entries`, поэтому проверки `-version` в тестах предпроверки не меняются. Длительность ответа = длительность дубля в сценарии (`take_durations[i]`), размер кадра = размер окна последнего запуска.
- Контракт с 03-03: путь к файлу — **последний** аргумент вызова ffprobe; формат ответа — `{"streams":[{"codec_type":…,"codec_name":…,"width":…,"height":…,"duration":"5.000000"}],"format":{"duration":"5.000000"}}` (длительности — строки, как у ffprobe 9.0.2).
</objective>
