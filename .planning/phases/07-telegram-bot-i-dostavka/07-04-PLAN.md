## Phase Goal

**As a** автор или друг из белого списка, **I want to** отправить боту демку файлом (до 2 ГБ через локальный `telegram-bot-api`) или ссылку FACEIT и видеть место в очереди и ход записи, **so that** готовый ролик приходит в чат новым сообщением, а при сбое приходит понятная причина — и незнакомцы не могут занять ни диск, ни очередь.

<objective>
Доступ к боту: команды управления белым списком, выбор игрока и полная проверка путей обхода белого списка до `getFile`. Белый список в `bot::dispatch` уже работает (план 07-02); здесь он доказывается тестами на все виды входа и обрастает командами.

Purpose: незнакомец не может ни заставить сервер скачать файл, ни занять очередь, а админ управляет списком из чата (критерий 1, BOT-01, BOT-02, BOT-03).
Output: команды в `bot/commands.rs`, функции пользователей в `users.rs`, тесты `tests/bot_access.rs`.

**Решения на усмотрение Claude (CONTEXT «Claude's Discretion»; исследование §9, §12; Assumptions A6):**
- Админ — пользователь с `role = 'admin'` в базе сервера; первого админа заводит оператор командой `cs2-server user add <имя> --tg <id> --admin` (доступ к серверу = доверие автора). Отдельного списка админов в конфиге нет: один источник правды. `/adduser` создаёт только участников.
- Форматы: `/adduser <Telegram-ID> [имя]` (имя по умолчанию `tg<ID>`, лишние аргументы и флаги — отказ с подсказкой), `/removeuser <Telegram-ID>`, `/users` (строки «имя — ID — роль — игрок — убран/активен»).
- Убирание — мягкое (`users.removed_at`), строку удалить нельзя (`jobs.user_id REFERENCES users(id)`); повторный `/adduser` того же ID снимает отметку. Убрать админа через чат нельзя.
- Убранный друг: новые сообщения — как от незнакомца; его принятые задачи доходят до конца и доставляются (A6, «дать задаче закончиться, затем блокировать»). Админу при `/removeuser` бот сообщает число активных задач друга.
- `/player` без аргумента показывает текущего игрока; с аргументом — сохраняет: 17 цифр с префиксом `7656` → `player_steam` и `player_name`, иначе только `player_name`; запрещены управляющие символы, U+200E/U+200F, U+202A…U+202E, U+2066…U+2069, U+2028, U+2029, U+FEFF; длина 1-64 символа.
</objective>
