## Phase Goal

**As a** автор или друг из белого списка, **I want to** отправить боту демку файлом (до 2 ГБ через локальный `telegram-bot-api`) или ссылку FACEIT и видеть место в очереди и ход записи, **so that** готовый ролик приходит в чат новым сообщением, а при сбое приходит понятная причина — и незнакомцы не могут занять ни диск, ни очередь.

<objective>
Настоящий клиент Bot API для локального `telegram-bot-api` и закрытие утечки токена через имя рабочей папки bot-api. Бот (07-02) работает через трейт `Tg`; здесь появляется его боевая реализация, проверенная поддельным HTTP Bot API без сети и без настоящего токена.

Purpose: живой стенд (07-11) и `serve` (07-10) получают проверенный клиент с правильными тайм-аутами и классификацией «могло дойти / не дошло»; токен не утекает ни в одной форме.
Output: `tg/http.rs`, `ureq` в зависимостях сервера, `Redactor` с формой `~`, `FakeBotApi` в общем стенде тестов, тесты `tg_http` и расширенный `secrets`.

**Решения (исследование: «Standard Stack», «Тайм-ауты клиента (ureq 3)», «Разбор ответа Bot API», §1, §6, §8; Assumptions A7, A10):**
- `ureq` переносится из `[dev-dependencies]` в `[dependencies]` с той же строкой `ureq = { version = "3", features = ["json"] }` — `Cargo.lock` не меняется (dev-зависимости уже в нём), охрана `deps.rs` не затронута (не path-зависимость). Отказ от TLS-признаков не гарантирован унификацией признаков воркспейса, поэтому безопасность держится на проверке адреса: только `http://` на `127.0.0.1`, `localhost` или `[::1]` с портом.
- Три агента: управляющий (`timeout_global` 30 с, `timeout_connect` 5 с), опрос (`timeout_global` = таймаут опроса + 15 с), передача (`timeout_connect` 5 с, `timeout_recv_response` = настраиваемый таймаут передачи, по умолчанию 60 мин). Все с `http_status_as_error(false)` — `ok:false` разбирается самим клиентом.
- Классификация (исследование §6): тайм-аут соединения или разрешения имени и отказ в соединении — запрос не ушёл (`sent: false`); любой тайм-аут или обрыв после начала отправки — `sent: true`.
- Обработчик фасада `log` в сервере не ставится (A7): ureq пишет адреса с токеном на уровнях debug/trace.
</objective>
