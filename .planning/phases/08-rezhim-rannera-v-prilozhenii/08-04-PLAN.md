## Phase Goal

**As a** автор с CS2 на своём ПК, **I want to** чтобы приложение само работало раннером сервера, **so that** задача друга с сервера шла через мою обычную очередь карточкой с журналом, этапами, отменой и «Повторить», не мешала моим задачам, сама продолжалась после перезапуска, а без адреса сервера приложение работало как в v1.0.

<objective>
Приложение становится хозяином раннера: адрес сервера в настройках, токен в отдельном файле с суженным доступом, поток раннера с воротами по виду очереди и наблюдателем, который ведёт строку состояния, удержание карточки и журнал итогов выдачи. `App::new` подключает хаб и ветку удалённых карточек к очереди через `start_with_hook`; без адреса поток раннера не создаётся.

Purpose: соединить готовые части (08-01 срез, 08-02 ворота и наблюдатель, 08-03 жизненный цикл карточки) в работающее приложение, которое можно проверить без окна (`RemoteRunner` с подставными зависимостями) и которое окно плана 08-05 только показывает.
Output: `Settings.runner_server`, модули `remote::token` и `remote::control`, проводка в `App::new`, тесты на настоящем сервере.

**Решения автора, которые реализует план:**
- D-02: токен — файл `token` в каталоге раннера (`%LOCALAPPDATA%\cs2cinema\runner`, тот же, что у `cs2-cli runner`) с отключённым наследованием ACL; не в `Settings`/`settings.json`; значение читается только в `runner::Token`.
- D-04: потолка ожидания удержанной задачи нет; пока карточка сервера ждёт очередь, состояние «Выполняю задачу с сервера #N» остаётся, а причина ожидания видна в окне (план 08-05).

**Ограничения фазы:** `queue::start` не меняется (приложение зовёт `start_with_hook`); без адреса — ноль потоков раннера и ноль сетевых запросов; одна запись за раз; токен не попадает ни в журналы, ни в базу, ни в состояние, ни в `settings.json`; строки по-русски.

**Решения на усмотрение Claude (исследование «Ответы» §4-§5, «Pitfall 3», «Pitfall 4», «Pitfall 6», A1, A4):**
- Хаб и `queue_runner` подключаются к очереди всегда: адрес можно задать без перезапуска приложения, а для строк без `external_ref` обёртка вызывает прежний `jobs::runner`, хук возвращает пустой совет — поведение локальных задач то же, что в v1.0.
- Каталог раннера и замок `runner.lock` (`File::try_lock`) — те же, что у `cs2-cli runner`: приложение и консольный раннер не запустятся вместе на одной папке.
- Если рядом с `cs2cinema.exe` нет `cs2-cli.exe` (в релизном zip они лежат вместе, `release.yml`), раннер не запускается, а состояние называет причину; на небезопасный путь без дочерней предпроверки приложение не переключается.
- Остановка раннера при открытой карточке сервера отменила бы её (`Tee::cancelled`): смена адреса или токена откладывается до закрытия карточки (`pending`), выход из приложения по-прежнему безопасен (задача продолжится после запуска).
- Ворота закрыты и при пустых путях HLAE/CS2: задача, которую нечем записать, сожгла бы выдачу друга сбоем окружения.
- A1 (сужение доступа `icacls` без повышения прав) проверяется кодом выхода `icacls`; при отказе токен не сохраняется. Живая проверка прав файла — `<human-check>` плана 08-05.
</objective>
