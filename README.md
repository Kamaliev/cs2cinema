# cs2-cli — хайлайты из матча FACEIT

```
export FACEIT_API_KEY=...        # ключ FACEIT Data API с доступом к Downloads API
cargo run -p cli -- https://www.faceit.com/en/cs2/room/1-<uuid> --length 60
cargo run -p cli -- demo.dem.zst --list      # локальная демка, только список хайлайтов
```

## Установка и проверка на Windows

Нужно один раз поставить:

1. **Git** — https://git-scm.com/download/win (понадобится и cs2-cli: он вызывает `git` для проверки релизов карт);
2. **Rust** — https://rustup.rs (rustup-init.exe). Rust на Windows просит **Visual Studio Build Tools** с набором
   «Desktop development with C++» — согласитесь на установку, без него не соберутся `zstd` и `ring`;
3. **Python 3.11+** — только для `scripts/update_maps.py` (можно пропустить);
4. **ffmpeg** (в PATH) — только чтобы склеить итоговый ролик; для HLAE-записи — https://github.com/advancedfx/advancedfx/releases.

Затем (PowerShell):

```powershell
git clone https://github.com/Kamaliev/cs2cinema; cd cs2cinema
git apply cs2cinema-changes.patch          # если изменения пришли патчем (см. ниже); иначе просто распакуйте архив поверх
git lfs pull                               # демка из репозитория (283 МБ)
cargo test --release                       # все тесты, ~1-2 мин на первую сборку
$demo = (Get-Item .\1-3e7db9e3-*-1-1.dem).FullName
cargo run --release -p cli -- $demo --list           # найденные хайлайты
cargo run --release -p cli -- $demo --out out\test  # полный прогон: монтаж, highlights.cfg, assemble.bat
cargo run --release -p cli -- --list-cameras         # каталог камер
```

Проверка с реальной демкой и картой (сверяет позиции, углы, стены):

```powershell
$env:CS2_TEST_DEMO = $demo
$env:CS2_TEST_MAPS = (Resolve-Path .\maps)   # появится после первого запуска cs2-cli (геометрия скачивается сама)
cargo test --release -p positions --test real_demo -- --nocapture
```

Матч по ссылке FACEIT (нужен ключ Data API с доступом к Downloads API):

```powershell
$env:FACEIT_API_KEY = "ваш-ключ"
cargo run --release -p cli -- https://www.faceit.com/en/cs2/room/1-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx --length 60
```

Запись в игре (**эту часть я не мог проверить**): запустить CS2 через HLAE, открыть демку (`playdemo <имя>`),
скопировать `out\<матч>\highlights.cfg` в `game\csgo\cfg`, выполнить `exec highlights`; клипы появятся в `clips\`,
затем `assemble.bat` склеит их в `highlights.mp4`. Если какая-то консольная команда не сработает, пришлите
текст ошибки из консоли игры — команды собраны в `crates/renderer` (`Dialect`).

Пайплайн (по крейтам):

| крейт        | что делает |
|--------------|------------|
| `faceit`     | ссылка → id матча → demo_url → скачивание `.dem.zst` |
| `demo`       | контейнер демки, protobuf, вложенные сообщения пакетов, игровые события, `userinfo` |
| `cs2`        | модель матча: раунды, убийства, игроки |
| `highlights` | серии убийств и эффектные одиночки + score |
| `director`   | монтаж: отбор по score, POV/chase/свободная камера, кривая замедления |
| `positions`  | позиции, взгляд, команда и «жив» по тикам из состояния сущностей (`source2-demo`) |
| `geometry`   | коллизионные меши карт (awpy-data), BVH, трассировка лучей — для стен |
| `renderer`   | `plan.json`, `highlights.cfg` для HLAE, `campath_*.xml`, `assemble.sh` (ffmpeg) |

Результат в `out/<id матча>/`. Запись: CS2 через HLAE → `playdemo` → `exec highlights`, затем `sh assemble.sh`.

## Камеры (`crates/director/src/rig.rs`)

41 пресет в таблице `PRESETS`: орбиты, наезды/отъезды, краны, ракурсы, широкие планы, раскрытие через
жертву, групповые планы, вайпы взглядом, зумы (punch-in, snap, dolly zoom). `cs2-cli --list-cameras`
печатает каталог с оценками на тестовой сцене.

Для каждого окна (интро, нарезка на средних убийствах, финал) режиссёр строит путь каждого подходящего
пресета и считает красочность 0..1:

| компонент | вес | что меряет |
|-----------|-----|------------|
| видно килл | 0.30 | убийца и жертва в кадре, в момент убийства вес ×3 |
| людность   | 0.16 | сколько ещё игроков в кадре (до 4) |
| кадр       | 0.12 | герой ближе к центру, комфортная дистанция |
| плавность  | 0.10 | угловая скорость (для вайпов лимит выше) |
| подача     | 0.12 | драматичность пресета vs tier хайлайта |
| разнообразие | 0.20 | штраф за повтор пресета/категории |

Камера внутри игрока обнуляет оценку.

**Стены.** В демке геометрии карты нет — она в файлах игры. Берём готовые коллизионные меши сообщества
([awpy-data](https://github.com/pnxenopoulos/awpy-data), релиз `geometry.zip`, 24 карты, формат `AWMH`).
Они принадлежат Valve, поэтому в репозитории не хранятся: при первом запуске скачиваются в `./maps`
(`--maps <папка>` или `$CS2CINEMA_MAPS`; `--no-walls` — без стен). С геометрией:

* «пружинный подвес»: если между героем и камерой стена, камера подтягивается к герою;
* кадры, где убийца или жертва закрыты стеной, не получают баллов за «видно килл»;
* пролёт камеры сквозь стену режет оценку в 3 раза.

На демке из репозитория без стен в плане было 9 закрытых кадров из 20 и 5 пролётов сквозь стены, со стенами — 0 и 0.
Меш упрощён и содержит только окклюдеры (без playerclip/glass), двери и динамические объекты не учтены.
Зум POV-камер — кривая `zoom` (множитель FOV → `mirv_fov`), рядом с замедлением на убийствах;
у снайперских убийств зум глубже.

## Актуальность геометрии карт

Карты меняются с обновлениями игры, поэтому меши привязаны к версии игры (`maps/maps.json`):

* **По умолчанию** `cs2-cli` раз в сутки сверяется с последним релизом awpy-data (по тегам; тег = ClientVersion
  игры) и при выходе нового скачивает меши заново. Сеть недоступна — работает на сохранённых.
  `--refresh-maps` — сверить сейчас, `--offline` — не ходить в сеть.
* **Из файлов вашей игры**: `python3 scripts/update_maps.py` находит CS2 (Steam, все библиотеки из
  `libraryfolders.vdf`, либо `--cs2-dir` / `$CS2_DIR`), читает ClientVersion из `steam.inf` и, если меши
  старее игры, извлекает физику карт через Source2Viewer-CLI и конвейер awpy-data, затем записывает
  меши и версию в `maps/`. `--check` только сообщает «актуально / нужно обновить» (код выхода 0/1).
  Такие меши `cs2-cli` не перезаписывает релизом; если игра обновилась после извлечения, он напишет
  «запустите scripts/update_maps.py».

Скрипту нужны Python 3.11+ и git; Source2Viewer-CLI скачивается сам (все ОС и архитектуры).
На поддельной установке проверены: поиск игры, клонирование конвейера, скачивание и запуск Source2Viewer-CLI,
метка версии, логика «актуально/устарело». Реальное извлечение из VPK я проверить не мог — игры в среде нет;
конвейер awpy-data сам помечает пути внутри VPK как `TODO(verify)`, хотя его CI-релизы строятся этим же кодом.

## Проверено на реальной демке

Демка FACEIT из репозитория (de_nuke, 283 МБ), сверка с независимым парсером `demoparser2`:

* события: 173 убийства после `begin_new_match` — совпадает;
* позиции: расхождение ≤ 0.8 юнита (интерполяция между замерами), «жив/мёртв» 100%;
* углы: у `source2-demo` `m_angEyeAngles` сдвинуты на 180° (pitch и yaw) — в `positions` исправлено;
  на убийствах стрелок смотрит на жертву у 170 из 173 (медиана 0.6°);
* весь прогон (разбор + позиции + монтаж) ≈ 5 с.

Тесты на реальной демке: `CS2_TEST_DEMO=/path/to/match.dem cargo test --release -p positions`
(без переменной пропускаются). Для проверок со стенами добавьте `CS2_TEST_MAPS=<папка с *.mesh>`.
Луч «стрелок → жертва» чист у 145 из 158 обычных убийств (92%) — геометрия и демка в одной системе координат.

Особенности FACEIT-демок (SourceTV): нет событий `round_start`/`round_end` — раунд начинается на
`round_prestart`; `round_prestart` идёт за ~1 с до `begin_new_match`, поэтому этот раунд сохраняется.

## Что не проверено / не сделано

* Команды HLAE/CS2 (`spec_mode`, `spec_player_by_accountid`, `mirv_campath`, `mirv_fov`, формат campath XML)
  собраны в `crates/renderer` (`Dialect`) и требуют проверки в игре — запустить запись я не мог.
* Меши карт соответствуют версии игры релиза awpy-data, а не патчу демки; после обновления карты возможны расхождения.
* Разбор сущностей (`crates/positions`) делает `source2-demo` (MIT/Apache-2.0), а не собственный
  код проекта; он спрятан за `positions::Track`, который реализует `director::PositionSource`,
  так что заменяется без правок в остальных крейтах.
* Клатчи пока не определяются (теперь есть всё нужное: `Track::team_at` и `is_alive`).
