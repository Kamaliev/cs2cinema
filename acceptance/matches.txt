# Приёмочный набор фазы 4 «Очередь без присмотра».

# Правила набора:
#   * ровно 5 матчей FACEIT, по одной ссылке (или голому id матча) в строке;
#   * все матчи — bo1 (берётся демка №0) на 5 РАЗНЫХ картах;
#   * в каждом матче играл ник из настроек приложения (ролик монтируется про него);
#   * матчи свежие: демки FACEIT со временем удаляются, а скачать их нужно хотя бы один раз;
#   * пустые строки и строки, начинающиеся с «#», пропускаются.
#
# Файл встраивается в cs2cinema.exe и cs2-cli.exe при сборке: после правки нужна пересборка.
